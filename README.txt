Life Settings 3.0 — 更新与主持指南

一、安装（适用于前面的 v1/v2 自建服务器）
1. 宝塔文件管理进入 /www/wwwroot，上传 ZIP 并解压，得到 life-settings-update-v3 文件夹。
2. 不要手动覆盖原 life-settings 或 data 目录。
3. 在宝塔终端执行：
bash /www/wwwroot/life-settings-update-v3/UPDATE.sh
4. 看到“升级成功”后，用 Ctrl+F5 刷新主持页面：
https://live.zirui1121.top/life.html?mode=host
如果尚未配置 HTTPS，请先使用 http；手机系统分享通常需要 HTTPS。
5. 正式演示建议创建新房间，下载 Back up host key，使用 Open projection 投屏。
6. 域名、SSL、反向代理、博客均不需要修改。

更新先停止服务并完整备份，再替换程序并自动迁移数据库。旧数据不删除；v2房间可继续使用，v1房间格式不参与新版互动。升级失败自动恢复旧版本。
备份位置：/www/backup/life-settings，终端会打印具体文件名。
人工恢复（会回到备份时的数据；升级后的目录仍保留）：
bash /www/wwwroot/life-settings-update-v3/ROLLBACK.sh /www/backup/life-settings/具体备份.tar.gz

二、本次变化
1. 去除绿色表情图标。标志改为 SVG 线条图形，手机主标题分行，房间信息单独一行；选项为暖橙色双列卡片。
2. 主内容英中对照，导航、按钮、状态、主持界面操作说明采用英文。
3. 每次点击选项自动保存，不再逐项点击保存。快速连续点击会依序提交；失败显示 Not saved 和 Retry，未保存状态不会冒充成功。
4. 抽奖公开结果只含编号；主持人私有名单仍可查编号对应姓名。抽奖资格、随机性、去重和结果持久化不变。
5. 增加同档案不同标签的角色排序实验，由主持人控制开场和揭晓。
6. 增加预测全班修改比例，主持人控制开场和揭晓；揭晓时冻结比例快照，之后继续修改不会改变对照答案。
7. 结尾生成纪念图片，提供4句英中对照文案、自定义最多120字符、Paper/Night/Sunset三种样式。图片包含句子与个人设置，不含名字。

三、建议主持顺序（约10分钟）
- 0:00–1:00：让同学扫码，输入昵称和性别预设，观察锁定设置。
- 1:00–2:20：Open experiment。每人收到随机的男性或女性标签，其他档案内容完全相同。标签分配与本人所选性别无关。
  同学按推荐顺序点击三个角色；完成3项自动保存。Reveal comparison 后锁定答案，并显示每组人数和首选角色统计。
  两组接近也可以讨论；课堂数据不能证明标签造成了差异，不要预设一定会出现某种结果。
- 2:20–6:30：逐项 Unlock setting，结合课文讲解，听众点击选项自动保存。保持公开汇总隐藏，给预测留悬念。
  “Confirm current settings”用于主动确认保留/完成状态，不是修改选项的保存按钮。未点确认也会统计已成功保存的修改。
- 6:30–7:30：Open predictions。同学拖动0–100%滑块，松手自动提交。预测准确率不影响抽奖。
  Reveal & freeze 同时冻结实际比例、公开预测分布和全班统计；个人手机显示预测误差。
  分母为全部已加入人数；尚未操作也计入分母。改回全部默认值不再算修改。实时比例以后可继续变化，预测答案保持揭晓时快照。
- 7:30–9:00：全部解锁后 Start finale，全场 Configured by: You。听众选择句子、样式，Generate image。
- 9:00–10:00：Lock roster 停止新增参与，Draw 3 numbers 等概率不放回抽出最多三个编号。
  抽奖仅一次。测试请使用测试房间，正式展示新建房间。

四、手机图片保存
- Generate image 后直接显示 PNG 预览。
- Download PNG：下载到设备；浏览器可能先放进“文件/下载”。
- Share / Save：系统支持文件分享时打开分享菜单，可选择“存储图像”等操作。
- iPhone / 微信：长按预览图片，选择保存图片。无此选项时在Safari/Chrome打开。
- 网页不能保证或强制直接写入相册，最终由系统与浏览器决定。
- 句子和图片在设备本地处理，不上传自定义文字，也不需要AI服务。

五、上线验收
A. 用测试房间，电脑主持、手机移动数据扫码。
B. 未解锁不能改；解锁后快速点击多个选项，等待 Saved automatically，刷新后应保留最后选择。
C. 排序实验开场前不可提交，揭晓后不可修改。参与者在揭晓前看不到分组统计。
D. 预测开场前不可提交，揭晓后不可更改；揭晓后再改设置，实际预测答案应不变。
E. 触发结尾，生成默认及自定义中文图片，检查换行并长按保存到相册。
F. 只显示中奖编号，刷新不重新抽奖。
G. 主持凭证私自保管，投屏使用 Open projection，不投影自己的私有名单。
